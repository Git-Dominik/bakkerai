# BakkerAI

AI chatbot for bakery students at Talland College. Ask questions about recipes, techniques, theory, and school work.

## Quick start

```bash
bun install
bun run migrate
bun run dev
```

The app runs on `http://localhost:3000`.

## What this project does

- User login and register
- AI chat for bakery-related questions
- Saves chat history
- Admin page to view users and chats

## Tech used

- Bun
- TypeScript
- Elysia
- Prisma
- SQLite

## Project folders

```text
public/   - frontend pages
src/      - backend logic and routes
prisma/   - database schema
```

## Useful commands

